# Recorded sounds (CC0)

Four recorded sounds, all from Freesound and dedicated to the public domain (CC0 1.0), so they
can ship here. Credit is not required; it's given anyway. The licence record for each is next to it (`*.license.json`).

| File | What it's for | Original | Creator |
